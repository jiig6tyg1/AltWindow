# AltWindow 1.00

日本語 · [English](README.en.md)

Option＋Tabでウィンドウ単位に切り替える、Mac用のメニューバーアプリです。同じアプリの複数ウィンドウを一覧表示し、Optionを離すと選択したウィンドウへ移動します。

![切り替え一覧のデモ](Resources/Switcher-preview.png)

画像はデモ表示です。実ウィンドウではプレビューを表示します。

macOS 14以降が対象です。macOS 26以降はネイティブLiquid Glass、14/15では背景ぼかしを使います。同梱のローカルビルドはApple Silicon用です。実機で確認したOSと未検証の構成は [RELEASE.md](RELEASE.md) に記載しています。

## はじめに

1. 常用する場合は `AltWindow.app` をアプリケーションフォルダへ移動してから起動します。
2. 設定画面から「アクセシビリティ」を許可します。キーボード入力が有効にならない場合は「入力監視」も許可します。
3. サムネイルを使う場合は「プレビュー画像」の「許可」から、macOSの「画面収録」（OSによっては「画面とシステムオーディオの収録」）でAltWindowを有効にします。
4. macOSに再起動を求められた場合はAltWindowを終了して開き直します。

アクセシビリティと画面収録は別の権限です。画面収録を許可しなくても、アイコンとタイトルで切り替えできます。再ビルド・署名変更・移動によって権限の再登録が必要になる場合があります。旧WindowHopとの同時起動は避けてください。

## 操作

| 操作 | 動作 |
| --- | --- |
| Option＋Tab | 一覧を開く／次へ |
| Option＋Shift＋Tab | 逆順 |
| Optionを離す／Enter | 確定 |
| 矢印キー | 選択を移動 |
| Esc | キャンセル |
| カードをクリック | そのウィンドウへ切り替え |

設定の「サムネイルの大きさ」で小・中・大を選べます。初期値は中です。

macOS標準のメニューバーメニューから「ウィンドウを表示」「設定」「終了」を選べます。アプリをもう一度開いても設定画面を表示します。設定のデモは架空のウィンドウで見た目を確認する機能です。実際のChromeなどを表示するには、メニューの「ウィンドウを表示」を使ってください。

設定の「ログイン時にバックグラウンドで起動」をオンにすると、次回のログインから設定画面を開かずメニューバーに常駐します。オフにすると自動起動の登録を解除します。macOSの承認が必要な場合は「ログイン項目を開く」から許可してください。表示はOSの登録状態に追従します。更新だけでは自動起動を有効にしません。

ショートカットはOption＋Tab固定です。

## メモリとプライバシー

サムネイルは長辺760pxに縮小し、最大8MiB・24枚をメモリに保持します。閉じて10秒後に画像とパネルを解放します。短時間の再表示にはキャッシュを使い、待機中は新たな画面キャプチャを開始しません。OSのメモリ圧迫通知にも応じて解放します。

外部通信・解析SDK・広告はなく、ウィンドウ名や画像をファイルに保存しません。詳細は [PRIVACY.md](PRIVACY.md)、実測結果は [PERFORMANCE.md](PERFORMANCE.md) を参照してください。

## 制約

- 標準アクセシビリティAPIを提供しないアプリや特殊ウィンドウは対象外です。
- Spaces／フルスクリーンをまたぐ移動は、対象アプリとmacOSの設定に依存します。
- 最小化中や取得できないウィンドウはアイコンで表示します。プレビューの失敗理由はカードに表示されます。
- 一覧は約2秒ごととアプリ切り替え時に更新します。開いた／閉じた直後は反映に少し時間がかかる場合があります。
- キャッシュの画像は直近の静止画です。動画のライブプレビューではありません。

## ビルドとテスト

Xcode 26以降（macOS 26 SDK以降）が必要です。外部Swiftパッケージへの依存はありません。ビルド先のAltWindowを終了してから実行してください。

```sh
bash build.sh
swift test --disable-sandbox
```

親ディレクトリへ `AltWindow.app` を生成します。`ALTWINDOW_BUILD_DIR` と `ALTWINDOW_APP_PATH` で生成先を変更できます。別CPU向けのビルドは対応環境で行ってください。

GitHub ReleasesのZIPはApple Silicon用のアドホック署名・未公証ビルドです。Developer ID署名はなく、macOSが起動をブロックする場合があります。一般配布用の署名・公証手順は [RELEASE.md](RELEASE.md) を参照してください。ソースからのビルドも利用できます。

継続利用する開発ビルドは、`ALTWINDOW_SIGNING_IDENTITY`で同じ証明書を指定して署名してください。ローカル用には`ALTWINDOW_TIMESTAMP=none`を指定できます。証明書署名済みの出力をアドホック署名で上書きするビルドは停止します。

以前の仮署名版から更新すると、macOSの設定上は許可済みでも、古い署名の権限登録が拒否されることがあります。その場合はアクセシビリティの一覧からAltWindowを削除し、`/Applications/AltWindow.app`を追加し直して許可してください。画面収録でも同様です。Mac全体の再起動だけでは古い登録は更新されません。
